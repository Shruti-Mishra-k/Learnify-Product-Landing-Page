# 🎓 Learnify – Product Landing Page

## 📌 Project Overview

Learnify is a fictional online education platform designed to help students and working professionals learn new skills, explore courses, and achieve their career goals.

This project focuses on creating a modern, attractive, and responsive product landing page using Figma.

## 🎯 Objectives

- Design an attractive educational platform landing page.
- Create a user-friendly interface.
- Practice Figma Auto Layout.
- Create reusable UI components.
- Maintain consistent colors, typography, and spacing.
- Design desktop and mobile layouts.

## 👥 Target Audience

- College students
- Working professionals
- Online learners
- People interested in learning new skills

## 🛠️ Tools and Technologies

- Figma
- Figma Auto Layout
- Reusable Components
- Typography Styles
- Color Styles
- SVG Illustrations

## ✨ Main Features

1. **Navigation Bar** – Includes Learnify logo, Home, Courses, About, Contact, and Get Started button.
2. **Hero Section** – Introduces the platform with the heading "Learn Smarter, Grow Faster."
3. **Feature Section** – Highlights Expert-Led Courses, Flexible Learning, and Course Certificates.
4. **Call-to-Action Section** – Encourages users to explore courses.
5. **Footer** – Provides platform information and navigation.
6. **Responsive Designs** – Includes desktop and mobile layouts.
